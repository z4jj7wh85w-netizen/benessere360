COME FARE
1. Rinomina la tua foto con il nome esatto scelto sopra.
2. GitHub > repository benessere360 > Add file > Upload files.
3. Carica la foto.
4. Commit changes.
5. Attendi circa 1-2 minuti e aggiorna il sito.
